# M10 verification: Wi-Fi bring-up (Samsung Galaxy XCover Pro, Samsung SCSC S620 / "wlbt")

Status: 🟨 2026-11-16. Joins a real WPA2 network, gets an address by DHCP and reaches the internet; Wi-Fi costs
~13 mW while connected (power save on). Pending: mDNS, reconnect after a router reboot, WPA3, pairing (M11).

## How it works
- **Driver**: built into the kernel (`CONFIG_SCSC_WLAN`); `wlan0` exists at boot. `ifconfig wlan0 up` loads the
  chip firmware from `/vendor/etc/wifi` (`mx140.bin`, HCF config files) and the MAC from
  `/mnt/vendor/efs/wifi/.mac.info`.
- **Firmware**: `vendor` is a logical partition inside `super` (dynamic partitions), so PhoneKit doesn't mount it.
  Instead the 2 MB of files are copied once from the ROM into `devices/samsung-xcoverpro/prebuilt/firmware/`
  (gitignored, never committed, like the kernel binaries) and put in the initramfs (`tree` entries in
  `initramfs.spec`, new in `scripts/mkcpio.py`). The MAC file is copied the same way, so `efs` is never mounted.
  ```
  adb pull /vendor/etc/wifi/. devices/samsung-xcoverpro/prebuilt/firmware/wifi/
  adb shell su -c 'cat /mnt/vendor/efs/wifi/.mac.info' > devices/samsung-xcoverpro/prebuilt/firmware/efs/mac.info
  ```
- **Userspace**: `scripts/build-wifi-tools.sh` builds static aarch64 `wpa_supplicant`/`wpa_cli` 2.11 (internal
  crypto: WPA2-Personal; WPA3/SAE needs OpenSSL or wolfSSL, later) and `iw` 6.9 against libnl 3.12.
- **paneld** (`paneld/wifi.c`): with `wifi.ssid` in the settings store it runs `wpa_supplicant` + busybox `udhcpc`,
  restarts them if they die, and writes `/run/wifi.ip`; with no network configured nothing runs.

```bash
scripts/ppctl.py wifi set "<network name>" "<password>"
```
```bash
scripts/ppctl.py wifi
```
