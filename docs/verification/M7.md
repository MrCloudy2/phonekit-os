## Bugs found and fixed on the way
- **RNDIS never transmits after boot** (host ARP fails, phone TX 0) when the phone boots straight into PANEL mode;
  runtime A→B switches always worked. paneld now self-heals: in mode B, if RX ≥ 8 and TX = 0 six seconds after the
  bind, it re-links the network function (once, max 3). Measured: healed 2 s after the host attached, ping 3 s
  after the control channel came up.
- **Lost touch lifts**: touch frames were dispatched once per `read()`, so a down + moves + lift arriving
  together looked like nothing (or a stale contact). Now every SYN_REPORT is dispatched; drawing still flushes once.
- **Injected long swipes were cut off** when `ppctl` disconnected (tty hang-up killed the injector child): the child
  now calls `setsid()` and ignores SIGHUP.
- Host client `ppj.Panel.events(timeout)` read only one chunk; now reads until the timeout.
- Menu → PANEL opens the widget page; with no layout it shows "WAITING FOR HOST" and the address.
