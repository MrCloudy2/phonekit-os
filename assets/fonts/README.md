# Fonts

Roboto (Light, Regular, Medium, Bold) by Google, Apache License 2.0 (`LICENSE-Roboto.txt`), from
https://github.com/googlefonts/roboto-2 release v2.138 (unhinted), subset to Latin + Latin-1/Extended-A + a few
symbols with `pyftsubset` to keep the initramfs small. Roboto is the font phonebox uses.

Roboto Mono Regular (instanced at wght 400 from the variable font, subset to ASCII, Latin-1, box drawing and
block elements for the RESCUE terminal) by Google, SIL Open Font License 1.1 (`OFL-RobotoMono.txt`), from
https://github.com/google/fonts/tree/main/ofl/robotomono.
